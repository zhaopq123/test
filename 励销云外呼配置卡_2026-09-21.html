先记住一句话：励销云里的「行业」是粗筛抽屉（按工商登记把公司归类），「关键词」才是决定名单质量的那个动作。
你想找的客户，和它被登记在哪个行业里，常常不是一回事——不要靠行业门类去"推理"客户，靠关键词去"命中"客户。

三、电话话术（照读即可）

这通电话只要三个结果：找到负责人 → 判断有没有场地机会 → 加微信 / 约下一步。
这通电话不要做的事：不追成交、不报方案、不主动讲回本和日销量、不把"买还是租"放在第一句。第一句只干一件事——问对方的经营现状，逼他回答一个具体问题，而不是回你一句"没兴趣"。

场景 1 ｜ 亲子乐园 / 儿童乐园 / 室内游乐

第一句

您好，我姓赵，北京星具探索的。我们给亲子乐园配无人冰淇淋机，想问一下，咱们园里冰淇淋现在是自己在卖吗？

对方说"有，自己在卖" → 接法

那挺好，说明这块有人消费。是自己人做，还是外面承包进去的？（听完再问）明白，那我不抢这块。咱们除了这个店，还有别的场地或者别的店吗？我们主要是在找能加的点位，占地一个多平方，现场需要有220伏电源，具体位置我可以过去帮您看。

对方说"没有" → 接法

那咱们加不加这种项目，是您能定还是老板定？（不管谁定，接着问）园里有没有一小块地方——出口、休息区、收银台旁边都行？占地一个多平方，现场需要有220伏电源，具体位置我可以过去帮您看。

对方说"有专门商户在做" → 接法

哦，是承包的还是抽成的？（听完）行，那我不掺和这块。您这儿还有别的位置吗，或者别的店？

对方问"你们是什么设备" → 接法

一台自助冰淇淋机。顾客自己扫码买、现场做，不用专门安排人收银。占地一个多平方，现场需要有220伏电源，具体位置我可以过去帮您看。（追问"要不要人管"）日常需要有人负责基础清洁和补料，具体操作我们会培训。然后立刻转回：咱们园里冰淇淋这块现在是自己在做吗？

对方问"多少钱" → 接法

11.98 万，一台，含税含运，含一年维保和售后。（随后主动收口）您要是觉得位置合适，我过去看一眼，帮您看看放哪儿合适。（追问回本）这个跟点位关系太大，电话里我不给您数，说了一定不准。

对方说"没兴趣" → 结束

行，那打扰您了。不硬推，我加您个微信吧，后面您这边想加项目，随时问我。（还是不加）好，那祝您生意好。

前台接电话 → 找负责人

您好，麻烦问一下，咱们园里放设备、加项目这类事，是老板在管还是店长在管？（前台问什么事）就是场地合作的事，一两句话，麻烦帮我转一下。（前台说不在）他一般什么时候在？我明天再打。

场景 2 ｜ 设备运营渠道（售货机 / 无人零售 / 自助设备 / 餐饮设备运营商）

这一类不是场地客户，是同行和渠道。不要按场地话术说，第一句就问他的业务结构。
第一句

您好，我姓赵，北京星具探索的。想跟您对个合作——咱们这边是自己有点位在运营，还是主要给客户供设备？

对方说"自己有点位在运营" → 接法

那正好。你们点位主要是哪一类场地？商场、乐园、景区这种人多、待得久的有没有？（听完）冰淇淋这个品类，你们客户问过吗？我们的机器可以走你们的点位，也可以你们这边分销。

对方说"主要给客户供设备 / 做项目" → 接法

那你们客户里，商场、乐园、景区这类多吗？我们这边是设备方，可以给你们做一个品类补充。

对方问"多少钱" → 接法

对外 11.98 万一台，含税含运，含一年维保和售后。（对方接着问渠道价）渠道怎么合作、什么价，得看量，要走内部流程，电话里我不定。

对方说"暂时不需要" → 结束

行，不打扰。我加您个微信，资料发您，后面有合适的项目随时找我。

前台接电话 → 找负责人

您好，麻烦问下，设备采购或者渠道合作这块是谁负责？我这边是做无人冰淇淋设备的，想跟负责人对一下。（前台不清楚）那老板或者运营负责人怎么联系？能不能给我个电话或者微信？

第一句

您好，我姓赵，北京星具探索的。想问一下，咱们园区里的消费点位，是招商那边管，还是自己运营？

对方说"招商管 / 外包" → 接法

那引进一个自助点位，是走招商流程，还是运营这边点头就行？园里现在还有空的位置吗？

对方说"自己运营" → 接法

那有没有想过在游客动线上加一个自助卖冰淇淋的？占地一个多平方，现场需要有220伏电源，具体位置我可以过去帮您看。

对方问"多少钱" → 接法

11.98 万，一台，含税含运，含一年维保和售后。（追问回本）这个跟点位关系太大，电话里我不给您数，说了一定不准。

对方说"没兴趣" → 结束

行，那打扰您了。不硬推，我加您个微信，后面有合适的点位随时找我。

前台接电话 → 找负责人

您好，麻烦问一下，园区招商或者商业运营这块谁在负责？我这边是做无人冰淇淋设备的，想跟负责人对一下场地合作的事。

通用追问 —— 四个场景都会碰到（必须照实答，不许编）

客户问"你们现在装了多少台了？"

跟您说实话，目前还没有正式落地点，实机情况我给您确认。您要是想看，我确认好再给您安排。

客户问"一天能卖多少？多久回本？"

这个我真不给您在电话里数——跟点位客流、客群关系太大，我说了也是猜。设备产能是一小时 40 杯，那是机器上限，不代表实际能卖多少。您要是有具体位置，我可以帮您看。

客户问"租金多少 / 押金多少 / 怎么分成？"

这块公司在定，我不在电话里给您报。您先把场地情况告诉我，我确认完给您回。

自己记住（不说出口）

不主动讲回本、利润、日销量；不编租赁、押金、分成的任何数字；不提竞品、不贬损同行；价格只有一句——11.98 万一台，含税含运，含一年维保和售后。

本组话术已取代旧版（原为手册《首次联系》章三条宣传式话术：报品牌→讲方案→问"有没有需求"，过长且易被直接挂断）。新话术保留手册"先问场景、先找负责人"的骨架，第一句不再出现租赁、方案、兴趣类问法。
本卡固定口径（电话里只报这一句）：
机型 = 无人冰淇淋机器人；对外主体 = 北京星具探索；价格 = ¥119,800 含税含运、含 1 年维保和售后。
不承诺回本周期、不承诺每天卖多少杯、不提竞品、不贬损同行。

四、每次拨号：五步 + 两个必须

  1. 01 定方向 —— 从上面梯队里挑一个，今天只打它。
  2. 02 输关键词 —— 名称 / 经营范围里填上面那组词。
  3. 03 看业务 —— 扫一眼经营范围，判断它到底干嘛的。
  4. 04 查重复 —— 先查这家在励销云里有没有记录，别重复陌拜。
  5. 05 找负责人 —— 找不到老板 / 运营负责人，就别往下谈。
电话的 KPI 只有三个：找到负责人 → 加微信 → 约上门/演示。
单价 ¥119,800、必须现场看设备，电话里不可能成交，别把目标定成"这通电话卖出去"。

五、打完一轮怎么修正方向

  • 每天查：新搜的客户有没有核实、有效沟通有没有留下一步、记录有没有写全。
  • 每周看：哪个关键词带来的有效线索最多 → 下周集中打那一类。
  • 落档按 8 阶段推进（待核实 → 已联系 → 有效意向 → 已邀约 → 拜访 → 报价 → 回款），只把有进展的往下一阶段推。
  • 客户分级：A 优先推进（场地明确+找到负责人）｜B 持续培育（场景匹配但时间/预算/决策人未定）｜C 暂停跟进（无场景、无付费基础、明确拒绝）→ 明确拒绝的客户暂时停止重复陌拜，后续有新的合作理由或新场景，再重新触达。

六、本阶段别碰的

  • 别用"金融业"等不相关门类充数，名单会杂到没法打。
  • 别只勾"零售业"整层——下面全是服装店、便利店、超市、药店。要找设备运营渠道，直接搜关键词，或往下选到"无店铺及其他零售业"。
  • 别在电话里编数字：租金、押金+分成金额、机器重量、公司门牌地址，库里都没有 → 统一答"这个我帮您确认一下"。
  • 明确拒绝的客户暂时停止重复陌拜，后续有新的合作理由或新场景，再重新触达；也别把一个客户的拒绝当成整个行业不行。
